\section{Limitations and Scope}
\begin{itemize}
\item \textbf{Small fixed batch.} Five starts per condition describe this batch only. No confidence interval, stable attack probability or wider model comparison is claimed.
\item \textbf{Unknown server state.} Effective sampling parameters, exact backend revision and scheduling behavior are not archived. The stated temperature is the client request.
\item \textbf{Agent-policy effect.} System instructions and bounded continuations are part of D7. The normal 5/5 outcome cannot be attributed solely to directory or shell fixes, or reported as single-turn performance.
\item \textbf{Observation boundary.} Native tool calls and returns are available, not complete system-call logs. Final hash preservation does not exclude a temporary modification followed by restoration. The child export lacks a second event-stream record.
\item \textbf{Dependencies and causality.} Edges represent recorded or inferred dependence. Reaching the injected note in an ancestor view does not prove it caused an edit, and the graph does not reveal hidden model reasoning.
\item \textbf{Incomplete evaluation scope.} General investigation tooling, source ranking, rarity scores, a matched flat-log baseline and analyst-time measurements are not completed. The report makes no comparative claims about them.
\item \textbf{Team metadata.} This artifact-level report does not assign individual authorship or contribution shares. Names, student identifiers and individual contributions require team confirmation before a course submission.
\end{itemize}
