\section{Conclusion and Remaining Work}
\label{sec:conclusion}

We set out to treat a new problem as two old ones.
The transfer works further than we expected.
The three requirements of code injection describe prompt injection without strain, and the comparison explains why the instruction-level defense fails where the externally enforced checks hold.
The Homework~2 graph model carries over to an agent's trajectory with its node and edge types intact, and with one rule about when results are read it yields a graph that is acyclic and in which reachability means possible influence.

The transfer stops at two places, and both became the technical content of the project.
The trajectory does not see inside shell commands, so the graph needs inferred edges; we added them and checked them against independent file hashes, with no disagreement on the runs we have.
And the model's context never forgets, so reachability names every input as a possible cause; this needs content evidence and counterfactual runs, which are designed and only partly exercised.
