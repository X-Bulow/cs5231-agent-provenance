\paragraph{Design decisions in the builder.}
The graph format is fixed in a specification with a worked example, and one of the checks compares the builder's output with that example, so the document and the code cannot drift apart.
The builder validates every graph it produces, including that it is acyclic.
Two details of the trajectory needed care.
Tool calls issued by one turn run concurrently, and the event stream logs them in completion order, so calls are numbered by the order in which the model issued them.
A failed call records an error in place of an output, and a failed edit must not create a file version.

\paragraph{Reproduction.}
From the repository root:
\begin{verbatim}
python3 provenance/build_graph.py --all artifact/runs graphs
python3 -m unittest discover -s provenance
make -C report
\end{verbatim}
The first command rebuilds every graph and prints a note for anything the graph cannot explain.
The last regenerates the tables of this report from the graphs and compiles it.
